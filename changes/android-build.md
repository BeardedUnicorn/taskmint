TaskMint can be built from source as an Android app (`pnpm tauri android dev`, see the README's Android section); there's no Android release yet. On a phone it has its timers, data and notifications. The tray, idle detection and the long-run reminder, folder backups, browser capture, server mode and updates stay on the desktop, and Export and Import don't work on Android yet. The desktop app is unchanged.
