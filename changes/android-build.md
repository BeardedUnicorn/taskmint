TaskMint can be built from source as an Android app (`pnpm tauri android dev`, see the README's Android section); there's no Android release yet. On a phone it has its timers, data and notifications, and Export, Import and Restore Exactly go through Android's own file picker. The tray, idle detection and the long-run reminder, folder backups, browser capture, server mode and updates stay on the desktop. The desktop app is unchanged.
