TaskMint runs on Android phones: each release has an APK (`TaskMint-X.Y.Z-android-arm64.apk`) to install on arm64 phones, and a later release's APK installs over it and keeps your data (see the README's Android section). On a phone it has its timers, data and notifications, and Export, Import and Restore Exactly go through Android's own file picker. The tray, idle detection and the long-run reminder, folder backups, browser capture, server mode and updates stay on the desktop. The desktop app is unchanged.
